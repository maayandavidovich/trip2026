# TravelOS V9.4.1

הגרסה מבוססת בכוונה על שפת העיצוב של V9.4: Hero גדול, תמונת Patagonia, כרטיסים בהירים, מרווחים נדיבים וניווט נקי.

שיפורים שנשמרו מהגרסאות האחרונות:
- תמונה רחבה לכל יעד/עיר
- תמונות בתוך מדריכי היעדים
- אזורים תחתונים בהירים ללא בלוקים שחורים
- "הפעולה הבאה" מחושבת ממשימות פתוחות
- מפה מקומית למסלול
- הזמנות ונתוני trip.json מעודכנים
- עובד מקומית/אופליין
